# RezervAz

> Azerbaijan-focused appointment booking SaaS platform for service businesses.

## Overview
RezervAz is an original software project created by Alahaddin Valiyev. It helps businesses manage services, staff, schedules, and customer appointments through a modern booking platform.

## Features
- Customer appointment booking
- Business management
- Service and staff management
- Scheduling system
- Dashboard experience
- Future notification and payment integrations

## Technology Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL
- Authentication: JWT
- Deployment: Vercel / Railway

## Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
